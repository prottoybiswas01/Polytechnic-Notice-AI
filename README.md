# পলিটেকনিক গাইড চ্যাটবট — সম্পূর্ণ ও প্রস্তুত সংস্করণ 🎓

এটি একটি সম্পূর্ণ ও স্বয়ংসম্পূর্ণ **Next.js** ওয়েব অ্যাপ্লিকেশন। এখন এটি সরাসরি Vercel বা অন্য যেকোনো হোস্টিং প্ল্যাটফর্মে কোনো প্রকার এরর ছাড়া সরাসরি ডিপ্লয় করা যাবে। 

প্রজেক্টটিতে একটি চমৎকার ও প্রিমিয়াম ডিজাইনের ল্যান্ডিং পেজ এবং নিচে-ডানদিকে একটি ফ্লোটিং এআই চ্যাট উইজেট রয়েছে।

---

## 🌟 আকর্ষণীয় নতুন ফিচারসমূহ:
1. **১-ক্লিকে ডিপ্লয়মেন্ট:** কোনো জটিলতা ছাড়াই সম্পূর্ণ প্রজেক্টটি Vercel-এ বিল্ড ও রান হবে।
2. **Gemini AI ও Google Search Grounding:** লাইভ গুগল সার্চ ইন্টিগ্রেশন সহ কারিগরি বোর্ডের ভর্তি নোটিশ, আসন সংখ্যা ও ২০২৬ সেশনের লাইভ আপডেট স্বয়ংক্রিয়ভাবে প্রদান করবে।
3. **Claude AI ইন্টিগ্রেশন:** আরও উন্নত ও ডায়নামিক উত্তরের জন্য Claude AI ব্যবহারের সুবিধা।

## 📁 প্রজেক্টের ফাইল স্ট্রাকচার

```
├── app/
│   ├── layout.js          ← মূল ওয়েবসাইট লেআউট ও চ্যাট উইজেট লোডার
│   ├── page.js            ← প্রিমিয়াম ল্যান্ডিং পেজ ডিজাইন
│   └── api/
│       └── chat/
│           └── route.js    ← API রুট (Gemini AI ও Claude AI)
├── components/
│   └── ChatWidget.js      ← ফ্লোটিং চ্যাট উইজেট UI
├── lib/
│   ├── admins.js           ← অ্যাডমিন/গ্রুপ কন্টাক্ট ইনফো
│   └── systemPrompt.js     ← AI-এর জন্য প্রম্পট গাইডলাইন
├── package.json            ← ডিপেন্ডেন্সি ও স্ক্রিপ্ট কনফিগ
└── .gitignore              ← গিট ইগনোর ফাইল
```

## 🚀 কীভাবে কাজ শুরু করবেন

### ১. লোকাল কম্পিউটারে রান করতে:
প্রজেক্টটি ডাউনলোড বা ক্লোন করে আপনার টার্মিনালে রান করুন:
```bash
npm install
npm run dev
```
এরপর ব্রাউজারে `http://localhost:3000` লিংকে গিয়ে প্রজেক্টটি লাইভ দেখতে পাবেন।

### ২. Vercel-এ ডিপ্লয় করতে (সম্পূর্ণ ফ্রি):
1. আপনার কোডটি গিটহাবে (GitHub) পুশ করুন।
2. [Vercel](https://vercel.com) এ লগইন করে আপনার রিপোজিটরি ইম্পোর্ট করুন।
3. **Environment Variables** এ গিয়ে (ঐচ্ছিক):
   - Key: `GEMINI_API_KEY`
   - Value: `আপনার-জেমিনি-কী-এখানে`
   - Key: `ANTHROPIC_API_KEY`
   - Value: `sk-ant-আপনার-কী-এখানে`
4. **Deploy** বাটনে ক্লিক করুন। ব্যস, আপনার সাইট লাইভ!
