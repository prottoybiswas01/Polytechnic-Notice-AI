# পলিটেকনিক গাইড চ্যাটবট — ভিত্তি (Base) সংস্করণ

এটা আপনার Next.js ওয়েবসাইটে বসানোর জন্য একটা রেডি চ্যাটবট সিস্টেম। এই ধাপে যা আছে:

- 🟢 ফ্লোটিং চ্যাট উইজেট (`ChatWidget.jsx`)
- 🟢 সার্ভারলেস API রুট যা Claude AI কল করে (`app/api/chat/route.js`)
- 🟢 সিস্টেম প্রম্পট — AI-এর নিয়মকানুন ও জ্ঞান (`lib/systemPrompt.js`)
- 🟢 এডমিন/গ্রুপ কন্টাক্ট লিস্ট (`lib/admins.js`)

পরের ধাপে যা যোগ হবে (এখন **নেই**, ইচ্ছাকৃতভাবে বাদ রাখা হয়েছে যাতে বেস সিস্টেমটা আগে ঠিকমতো কাজ করে):
- কারিগরি বোর্ডের ওয়েবসাইট থেকে অটোমেটিক আপডেট স্ক্র্যাপ করা
- চ্যাট হিস্ট্রি ডাটাবেজে সেভ রাখা
- অ্যাডমিন প্যানেল থেকে আপডেট লেখার UI

---

## ১. ফাইলগুলো কোথায় বসাবেন

আপনার Next.js প্রজেক্টে (App Router ধরে নিয়ে):

```
your-project/
├── app/
│   ├── layout.jsx          ← এখানে <ChatWidget /> বসাবেন
│   └── api/
│       └── chat/
│           └── route.js    ← এই ফাইলটা কপি করুন
├── components/
│   └── ChatWidget.jsx      ← এই ফাইলটা কপি করুন
└── lib/
    ├── systemPrompt.js     ← এই ফাইলটা কপি করুন
    └── admins.js           ← এই ফাইলটা কপি করুন
```

যদি আপনার প্রজেক্ট **Pages Router** (app/ এর বদলে pages/) ব্যবহার করে, তাহলে `app/api/chat/route.js`-এর বদলে `pages/api/chat.js`-এ বসাতে হবে এবং সিনট্যাক্স সামান্য আলাদা হবে — দরকার হলে বলবেন, ওটাও বানিয়ে দেব।

## ২. layout.jsx-এ যোগ করুন

```jsx
import ChatWidget from "@/components/ChatWidget";

export default function RootLayout({ children }) {
  return (
    <html lang="bn">
      <body>
        {children}
        <ChatWidget />
      </body>
    </html>
  );
}
```

## ৩. Anthropic API Key নিন

1. https://console.anthropic.com -এ গিয়ে অ্যাকাউন্ট খুলুন
2. একটা API key বানান
3. প্রজেক্টের রুটে `.env.local` ফাইল বানিয়ে লিখুন:

```
ANTHROPIC_API_KEY=sk-ant-আপনার-কী-এখানে
```

⚠️ **`.env.local` কখনো GitHub-এ পাবলিশ করবেন না।** `.gitignore`-এ এটা যোগ থাকা উচিত (Next.js ডিফল্টভাবে এটা বাদ রাখে)।

## ৪. নিজের তথ্য বসান

- **`lib/admins.js`** — আপনার ফেসবুক গ্রুপ/এডমিন আইডির লিংক বসান
- **`lib/systemPrompt.js`** — "সর্বশেষ আপডেট" অংশে ভর্তি/রেজাল্টের তারিখ, নোটিশ ইত্যাদি লিখুন। যখনই নতুন তথ্য আসবে, এই ফাইলটা আপডেট করলেই চ্যাটবট নতুন তথ্য জানাবে (কোড পাল্টাতে হবে না)।

## ৫. লোকালি টেস্ট করুন

```bash
npm install
npm run dev
```

ব্রাউজারে `http://localhost:3000` খুলে নিচে-ডানদিকে চ্যাট বাবল দেখতে পাবেন।

## ৬. ডিপ্লয় করুন (Vercel — ফ্রি)

1. কোড GitHub-এ পুশ করুন
2. https://vercel.com -এ গিয়ে রিপোজিটরি ইম্পোর্ট করুন
3. Vercel-এর Project Settings → Environment Variables-এ `ANTHROPIC_API_KEY` যোগ করুন
4. Deploy চাপুন — ব্যস, লাইভ।
